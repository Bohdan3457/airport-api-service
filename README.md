# Airport API Service

A RESTful API service for managing flight bookings, routes, airplanes, and orders. Built with Django REST Framework following clean architecture principles.

## Tech Stack

* **Python 3.10+**
* **Django & Django REST Framework (DRF)**
* **JWT Authentication** (`djangorestframework-simplejwt`)
* **OpenAPI & Swagger Documentation** (`drf-spectacular`)
* **Pillow** (Image upload support)
